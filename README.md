# 🎮 GPU-Based Tic-Tac-Toe Competition

## 📌 Project Description
This project demonstrates an interactive Tic-Tac-Toe competition between two decision-making players on a 3×3 game board.

## ✨ Features
- Two competing players (X and O).
- Automatic move selection.
- Winner and draw detection.
- Run Game option.
- Next Move option.
- Reset Game option.
- Move history display.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ▶️ How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Click **Run Game** to start the competition.
